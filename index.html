AI Ghostwriter with Hallucination Guardrails

MOD·06

Three-agent n8n pipeline that researches daily industry news, lets a human pick a story via Telegram, and ghostwrites an on-brand LinkedIn post with an AI-generated hero image and carousel — then publishes through Buffer after approval. The core problem wasn't generation, it was trust: a second-pass model verifies every summary against the real source article rather than the model's own citation, a deterministic gate rejects any story whose URL doesn't match the search API's real results, and the pipeline auto-regenerates once before ever bothering the human reviewer. Diagnosing a race condition between two parallel execution branches — traced via n8n's REST API down to the millisecond — meant moving the insert/skip decision into the SQL layer instead of a graph-level branch, eliminating it outright rather than papering over it with a longer wait.

n8n GPT-4.1 OpenAI Images Tavily PostgreSQL Buffer API Telegram Bot API
